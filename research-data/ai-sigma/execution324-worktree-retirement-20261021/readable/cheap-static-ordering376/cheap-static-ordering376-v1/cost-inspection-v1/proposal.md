## Exact proposed change and boundary

The sole production owner/call target is `crates/quoridor-ai/src/cheap_static_ordering.rs::validate_maps`; its sole current call remains prepare at154, reached by alphabeta Cheap at1016. No nnue/core/evaluator/caller/history/TT or mode API changes are proposed.

1. Initialize local81 u8 direction masks inside validate_maps. Keep the outer colour order0 then1 and the existing control call before each colour.
2. Keep cell/direction iteration order and every data/error predicate unchanged. In colour0, compute is_edge_open at exactly its current point; set the corresponding bit only when open, then perform the original checks. In colour1, use that same cell/direction bit. Enumerate the four direction slots before filtering absent neighbours so border directions cannot be remapped.
3. Retain every goal/range/sentinel/Lipschitz/descent/current-pawn check and original first-error precedence. If colour0 fails or is cancelled, return immediately; its partially filled local masks are discarded and never consumed by colour1. Keep legal destination rejection and all other prepare work unchanged.

Position is one copied immutable parent value; is_edge_open is a pure H/V geometry query. The second pass therefore sees exactly the prior open-edge boolean for the same `(parent,cell,direction)`, independently of either map's data. No new cache-validity assumption, proof marker, exemption or cross-parent lifetime is required. Invalid claimed data still fails at the same check/message/control ordering, including corrupted colour1-only data and stale walls. A missing cache does not allocate/use this local array.

Scores remain bit-identical i16 sums and booleans; combined main/continuation terms, priority tiers, policy, killers, TT/PV and deterministic ActionID ties do not change. All legal ids survive. No transition, leaf calculation, canonical history/repetition, TT key/reuse, update/age or selective-search rule is changed. The control polling points/count/order and NodeResult propagation are retained. Actual wall-clock cancellation/deadline outcomes can naturally occur at different elapsed times if execution changes; no same-time action claim is made. There is no extra uninterruptible pre-pass: first-colour checks populate masks as they already run.

The temporary has81 logical bytes, no heap/Arc/model/target state, and ends before child recursion. Actual compiler layout/spills/RSS/continuous peak and speed benefit remain UNKNOWN.
