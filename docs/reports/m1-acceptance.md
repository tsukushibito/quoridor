### Saved formats and recovery limits

The game key is `quoridor.m1.game.v1`: `{schemaVersion:1,rulesetId:"standard-2p-v1",match:{mode,humanSide,simulations},replay}`. `replay` is the generated Rust `SavedGame` with standard initial configuration, actions, ply and position key. The envelope accepts 0–4096 simulations (UI offers 48, 96, 192, 4096). The replay has at most 4096 actions and Rust's 64 KiB JSON input limit; the complete localStorage value is capped at 70,000 characters. The settings key is `quoridor.m1.settings.v1`: `{schemaVersion:1,nextMatch,reducedMotion}`, capped at 1024 characters. Saved strings are validated, not authenticated. A browser may erase localStorage independently of the app. When a write fails, the prior bytes remain if the browser's `setItem` is atomic; the UI reports the failure and the in-memory game continues. An invalid game slot is preserved until explicit clear or new-game replacement. Settings corruption is handled separately.
