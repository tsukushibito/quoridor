# NNUE型Quoridor AIの最高棋力へ向けた自律研究の目標

目標issue: `quoridor-4lc`。本書は継続して有効な研究目標を定義する。現在の期限・資源・担当配分は[現行実行枠](ai-sigma-continuation-20261001.md)、実行と記録は[共通規約](../development/ai-research-experiments.md)を参照する。過去版はGit履歴で管理する。

## 目標と評価

2026-10-03のユーザー指示により、最終目標は**NNUE型で最強のQuoridor AIを作ること**とする。NNUE評価とαβ探索を主候補に、ブラウザで利用できるRust/Wasm実装を研究する。「最強」は無条件の世界一や完全解法の証明ではなく、対象に選んだ有力な公開AIに対し、同じ計算資源・思考時間で最上位の棋力を実測する目標として具体化する。比較対象はSigmaQuoridor、Claustrophobia等から統括・検証担当が実行可能性と棋力の根拠を見て選び、版・実行場所・資源と判定条件を結果前に定める。CPUのみとGPUあり、複数の思考時間の成績を分けて評価し、一条件の結果を全条件の優位性へ広げない。

最初の到達目標は、固定したSigmaQuoridorと同じ計算資源・思考時間で同等水準以上のRust/Wasm AIを実装・検証すること。これは最終目標への段階目標であり、達成だけで研究全体を完了しない。native/localと製品ブラウザはそれぞれ実測し、一方の結果を他方の到達証明にしない。製品の技術要件は[AI設計](quoridor-3d-webapp-design-rust-wasm-v1.md)に従う。

基本経路は、(1) Sigmaの既存モデルを使う忠実な探索の実装と同等性評価、(2) 自己対局・学習・評価環境の整備と自前モデルでのSigma同等、(3) NNUEモデルとαβ探索の実装・学習・比較を経て最上位棋力を目指すこと。既存モデル・MCTSは基準実装、教師データ生成、対照として活用する。学習済みモデルの出所と、既存重みからの継続学習か初期重みからの学習かを記録する。段階の順序は研究上の優先順位であり、NNUEの特徴設計・距離計算・教師データ利用の軽い調査や必要な並行実験を禁止する完了待ちの規約ではない。具体の配分は現行枠内で統括が判断する。

特徴設計・距離計算・学習と比較の重要な仮説は[NNUE研究方針](ai-nnue-research.md)を参照する。同書の候補特徴や構成は実測で見直す設計案であり、新たな一律gateや固定係数ではない。

機能診断・性能測定・探索的対局と、正式な同等判定を区別する。小さい診断対局は[比較方法](ai-sigma-comparison-protocol.md)の最小条件と予算内で進められる。正式判定は対象版、モデル、規約、資源、時間、局面、集計、非劣性許容差・信頼水準、標本数・終了規則を結果前に定め、独立根拠で受け入れる。既存結果を見て条件を変更しない。

合法手、value視点、特徴・行動変換、キャンセル、応答性、メモリ、モデルの出所・配布条件を変更に必要な範囲で検証する。性能向上だけで棋力到達を認定しない。統括が独立検証を受け入れて目標達成を判定する。予算終了や未達を達成と区別する。
