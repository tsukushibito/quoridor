## Method choice, before results

Choose deterministic bounded DFS/minimax with an explicit heap frame stack, reversible private canonical cursor and exact-history memo. This is the smallest method whose proof rules can be audited directly. Search the supplied legal pawn actions in canonical order initially. No NN, heuristic cutoff, symmetry assumption, selective omission, distance-as-proof or learned ordering enters the proof. A nonterminal empty action list is a contract error (Unknown), not an inferred draw or loss.

A board-only retrograde table over 81*80*2=12960 ordered distinct-pawn/turn combinations per fixed wall topology does not encode the threefold context. It cannot establish exact Draw, Loss or history-independent Win for this task merely by lookup. A separately justified history-independent certificate/helper is a possible future optimization, with cost and proof conditions first; it is not part of this implementation. PNS/DFPN remain candidates only. There is no method comparison, sweep or new research decision implied by this contract.

For a child, negate its proven side-to-move value. One proven Loss child establishes parent Win even if other children remain unresolved. Parent Loss requires every legal child proven Win. Parent Draw requires all legal children proven Win or Draw, at least one Draw, and no unresolved child. Unknown is not Draw; an absent action is not proof. A proof is an exact game value for this history, not a depth-limited value. Choosing a proven nonterminal value requires a legal attaining action; terminal proofs have no best action. Unknown may return an explicitly unproven legal fallback.

Every nonterminal state has current occurrence count at most two. On a fixed topology with zero stocks there are finitely many exact board keys. Every nonterminal transition increments one count, so a path avoiding goals/third occurrences is finite (at most twice the 12960 board combinations before a third occurrence, conservatively including terminal goal combinations). This establishes mathematical termination without imposing ply200 as a game rule. Operational frame/node/deadline limits will usually stop much earlier and yield Unknown.

## Memo and bounded control

Memo keys must compare the complete canonical position and canonical sorted occurrence map, plus the rules namespace. Counts and keys are exact, never collision-only hashes. Maps contain pre-zero-stock positions as well; dropping them requires a separate proof and is not done initially. Absolute operational ply is retained in the memo key in the first implementation to prevent remaining-cap confusion. A complete proof can be memoized; unresolved, in-progress and cutoff nodes cannot. No path-cycle shortcut emits Draw. Reentrant calls keep no process-global memo or cursor.

Preflight reserves all configured capacities with fallible allocation and checked size arithmetic: explicit frames (each embeds81 pawn-action slots), undo tokens, cursor base/path, exact keys, flat memo entries and key-comparison scratch. No vector grows after reserve. Memo keys use canonical normalized full counts, exact position and absolute ply; per-call storage isolates rules namespaces. Cap payload AND actual reserved capacities, allocator/structure slack and transient old-plus-new allocations. The source kernel requires a platform-qualified total allocator overhead bound; missing attribution returns Unknown/AllocationAccountingUnavailable, not a zero charge. This is not a physical RSS certificate. It checks cancellation/deadline after each reserve and records partial allocation peaks on failed setup. Fixed kernel limits additionally reject frames/history/memo above4096 and heap limits above64MiB, bounding a single uninterruptible allocation or scratch insertion; actual admitted finite cases will use much smaller caps. Memo disabled explicitly by max_memo_entries0 is supported; a positive full memo refuses with Unknown/MemoLimit. No unresolved/partial key publishes a memo entry. Input history exceeding supported capacity declines before canonical construction. No silent limit enlargement.

Use the caller's monotonic clock abstraction compatible with native and Wasm; elapsed begins before validation/allocation. The kernel's private Control accepts elapsed/cancel/operational ply ceiling, with final elapsed sampled after storage and private cursor drop. The public adapter starts the same clock before prefix validation/replay and does not restart it at kernel entry. Poll every frame/edge, history visitor, memo entry/key comparison, reserve and proof publication. No uninterruptible whole-history sort/clone outside an accounted bounded step. Each frame stores its undo token, next child index, legal count, Win/Draw attaining actions and first unresolved reason. A child frame/history/operational-ply cutoff can stay unresolved while siblings are visited: a later proven Loss child still proves parent Win. Global node/edge/memo/heap/clock/cancel/contract errors stop the search. On all exits, unwind the private cursor with verified tokens; parent remains immutable. A malformed transition/undo/terminal/action yields Unknown/RuleContractViolation. Cleanup failure blocks proof publication; cancellation/deadline after cleanup also invalidates a pending proof. Report actual work/elapsed on every outcome.
