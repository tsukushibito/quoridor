# 自律研究の目標契約

目標Beads issue / 契約版 / ユーザー指示の参照:
統括ロール・スレッドID / ユーザーへの報告先:
達成したい状態 / 現在の基準 / 優先する指標:
対象機材 / 比較相手の固定版と設定 / 思考時間・メモリ制約:
達成判定 / 不確実性の扱い / 正しさ・応答性の必須条件:
研究範囲 / 変更を許可するコード・作業場所 / 製品統合の権限:
調査・実装・依存導入・外部取得・自己対局・学習の許可範囲:
CPU/GPU・LLM並行数 / メモリ・保存容量 / 累積時間・費用上限:
統括に委任する判断 / サブエージェントの許可範囲:
独立検証 / 証拠の保存 / 整理できる所有済み一時物:
ユーザーへの報告契機 / 予算終了・行き詰まり・pauseの停止条件:

統括はこの契約から個別の研究・実験契約を作り、目標達成まで課題を更新する。作業状態はBeadsを正本とし、この契約へ進捗一覧を複製しない。目標の提案とユーザーからの実行依頼を区別する。目標候補の記載だけで研究を開始しない。
